Recursive SOH forecast metrics
==============================

Task: later-cycle SOH forecasting using a lag-based linear model
Target: normalized SOH
Train/test split: first 70% cycles train, last 30% cycles test

Models:
- naive_last_observed: repeats the last SOH value seen in training
- lag_one_step_linear: uses observed lag features in the test window
- recursive_lag_linear: feeds its own predictions back as future lag values

Important note: recursive_lag_linear is stricter than the one-step lag test.
It does not use observed future SOH values as lag inputs after forecasting starts.
